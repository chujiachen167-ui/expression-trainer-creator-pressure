# V2 / 创作者监看台

状态：本地视觉验收版，未提交、未推送、未部署。

## 品牌判断

Read Yourself 面向自媒体创作者。首页可以有舞台感和鲜明姿态，训练页需要让人愿意长时间面对自己的表达。两者通过暖灰底色、灰紫品牌色和少量洋红强调保持联系，不要求重复同样的视觉强度。

V2 的语言是「导演监看器 + 场记纸带」。专业不是把所有参数摊开，艺术感也不是添加装饰。中心画面保持沉浸，创作身份通过 CREATOR TAKE、取景角标、实时口述纸带和少量高辨识状态色建立。

## 本轮落地

1. 保持中心舞台间距与数字观众 / 创作者窗口比例；不改 V1 配色与布局。
2. 左栏采用暖灰轻表面、深灰文字和分隔线。受众模板、观众类型、选题、压力等级各有独立层级；取消深色套卡与彩色压力按钮。
3. 右栏标题和收起动作分开，折叠把手固定在舞台与反馈栏的视线中段，具备可读标签、展开状态与键盘焦点。明细不在舞台上常驻。
4. 兴趣图取消实色面板和边框，用透明渐隐衬底、面积信号和更清楚的坐标保证亮画面上的刻度可读。纵轴 0–100，横轴会话时间；无有效数据不画假曲线。模拟边界说明和表格移入右栏展开项。
5. 反馈避免同一句建议重复显示，详细依据保留在最终报告。词语统计只在结束后报告中出现。
6. 实时转写成为舞台下方独立的“实时口述场记纸带”，不再与数字观众、创作者镜头或兴趣图争夺同一层空间。
7. 受众目标说明使用稳定文案键，动态切换模板后仍可在调控板里修改或清空；左栏窄宽下所有文字允许自然换行，不互相挤压。
8. 旧草稿只做一次布局迁移：清掉与当前首页 / V2 打架的位移和尺寸，保留 9 月 6 日文案和颜色。新保存的微调不会被反复重置。JS 项目配置与 JSON 副本保持一致。生产预览忽略浏览器草稿。

## 验收边界

检查侧栏选择、选题展开、压力选中状态、反馈收起 / 展开、图表空数据与时间刻度、结束后报告。录音识别准确率和线上部署不属于本次视觉验收结果。最终审美仍需 Founder 在常用窗口尺寸下确认。

# Read Yourself：两套完整首页提案

状态：独立可交互原型，供 Founder 人工选型；不等于正式发布。

## 如何选择

| | A：品牌先被记住 | B：效果先被看见 |
| --- | --- | --- |
| 首要印象 | 一张属于 Read Yourself 的品牌封面 | 一次看得懂、点得动的表达改善 |
| 主视觉 | 大字号 Read Yourself 与完整眼睛 / 嘴唇 / 相机 Logo | 可操作的句子示例与具体反馈 |
| 信息顺序 | 品牌 → 用途 → 开始 → 表达示例 | 用途 → 开始 + 表达示例 → 训练层 |
| 个性来源 | 字号对比、轻微倾角、衬线英文副标题、原有符号 | 对词句的细致标注、留白、编辑纸面式构图 |
| 手机处理 | 先标题与行动，再 Logo 与句子；不塞进小屏左右两栏 | 先用途与行动，再完整练习演示；三步仍可点按 |
| 主要风险 | 品牌更强，但理解具体机制比 B 多一步 | 更易理解，但品牌符号记忆不如 A 强 |
| 接入成本 | 主要是首屏重排与挑选保留的旧动效 | 需要维护示例内容；未来可替换为脱敏真实训练片段 |

建议：若这一轮主要为陌生用户传播，我偏向 B 的信息顺序；若你最希望建立独特品牌记忆，A 更值得继续。这个判断不替代你的审美选择。不要把 A 的所有品牌效果和 B 的整张练习台直接堆在一起。

## 相同部分

- 同一受众、功能事实、原有 Logo 和颜色家族，不用虚构用户数或留存提升百分比。
- 同一份三条表达示例和三个训练层文案。开始按钮进入已有 V1，不伪造登录、付费或即时诊断。
- 中文、英文可切换；切换只影响当前预览 URL，不读取或覆盖正式配置和浏览器草稿。
- 主用途与开始入口前置。两者不沿用旧版「大 V1 卡片被右侧长英文一起撑高」的布局。
- 页尾说明原型身份，保留真实项目、许可证和联系入口。
- 观众兴趣度仍属待完善能力；演示清楚标注为预置示例，不构造假的实时曲线。

## 文案改动提案（仅在预览中）

保留：Read Yourself；英文副标题 `When your ideas become content, would you read it yourself?`；V1/V2/V3 中文标题及正文意图。原有「终级实战演练」暂时原样保留；「终级」是否更正为「终极」交由 Founder 决定。

| 新增 / 调整 | 目的 |
| --- | --- |
| 「面向自媒体新手的镜头表达训练」 | 将受众和用途前置；来自项目已确认定位。 |
| 「从 V1 开始练习」 | 将入口说清楚，不新增产品能力。 |
| 「在发布之前，先听懂自己。」作为 B 主标题 | 提升现有页尾文案的层级，不改品牌名。 |
| 「先面对镜头，再面对观众。」 | 概括训练递进；不是效果承诺。 |
| 「保留你的个性。练清楚你的表达。」 | 新增页尾提案，表达产品立场，待 Founder 审核。 |
| 「表达示例 · 非实时诊断」及演示说明 | 明示预置示例与真正 AI 诊断的区别。 |
| 英文用途、按钮、训练层译文 | 本轮设计提案译文，未写回正式国际化词库，需人工确认语气。 |

A 的句子通过悬停、键盘聚焦或点击查看改写；没有重新引入「原句：」「精炼：」标签。B 的三步按钮用来解释操作阶段，句子本身同样不加这类前缀。

## 配色用途调整

保留粉白底、紫色品牌、粉色强调和青色辅助。为可读性增加深紫 `#5458a0` 与深粉 `#a92061`，正文采用暖深灰；原有淡紫用于 Logo。这是预览内的色彩用途调整，不替换你保存的官方主题。渐变只在训练层悬停时低强度出现，不铺满所有背景。

## 请优先验收

1. 打开 A 和 B，先不看解释，你愿意把哪张首屏发给朋友？
2. 用手机模式和英文模式各看一次，是否还像同一个品牌？
3. A 的句子交互、B 的三个步骤是否自然？
4. 选一套整体，再集中改比例、颜色和文字；不要先逐组件拼装。

# 首页参考与素材边界

观察日期：2026-09-05。研究对象是信息组织与品牌表达，不是可复制的开源模板。

## 四个参考

| 参考 | 实际可观察内容 / 借鉴机制 | 本次转化 | 不照搬什么 |
| --- | --- | --- | --- |
| [SpaceX](https://www.spacex.com/) | 前轮浏览器实际查看到大尺度行星画面、强标题与探索入口构成单一主视觉；本轮网页文本提取为空，因此不据此推断内部实现。 | A 的标题与原有眼睛 Logo 组成单一封面，保留首屏可见的训练入口。 | 黑底宇宙影像、商标、航天叙事以及重媒体资源。 |
| [Linear](https://linear.app/) | 页面正文将用途说明与具体产品操作界面相连，而不只陈列抽象能力。 | B 用可点按的表达示例说明反馈机制。 | 企业团队场景、客户标识、复杂工作台与任何业务数据。 |

除 SpaceX 前轮浏览器画面外，后三项本轮依据已打开网页的正文与内容结构，不声称已做逐像素视觉研究，也没有验证它们的移动端布局。此次原型的手机排版是本项目自行设计，不是对参考站移动版的复刻。

## 代码、字体、图片与许可

- 原型：原生 HTML / CSS / JavaScript 原创实现，随本仓库现有 LICENSE 管理；无新增第三方运行依赖、无付费组件。
- Logo：复用本仓库 `assets/brand/read-yourself-concentric.png`，保持原图；复用现有 `index.html` 的黑色转透明遮罩方式，仅在预览中着色。本次没有重新生成或编辑 Logo，也未重新审计该既有素材的来源。
- 字体：调用用户设备已有的 Aptos / Segoe UI / 苹方 / 微软雅黑及 Baskerville / Palatino / Georgia 回退；不下载或再分发字体文件，不增加字体授权费用。不同系统字形会有差异，不能当作跨平台像素一致承诺。
- 商业参考网站不是开源素材授权。未复制其代码、图片、视频、客户名单、商标或证言。
- 示例文本来自项目已有表达示例，英文为本轮提案译文。标记和改写是预设内容，不是接入数字人模型后的评估结果。

## 动效取舍

没有再次叠加 React 组件。A 只保留 Logo 悬停轻微扶正、句子交互切换、入口反馈；B 使用明确的分步状态。两者静态可读，支持系统减少动态设置，不加载标题模糊和滚动字幕引擎。若 Founder 选中某方向，后续接入正式页面时再决定是否恢复既有 True Focus / Warp Text / Marquee 的某一项，不默认全部恢复。

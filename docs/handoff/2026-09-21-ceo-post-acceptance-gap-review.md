## 二、发布前必须补齐

### P1 · Live2D 模型兼容与性能证据不足

- 尚未验证用户自有模型的完整 motion / expression / physics 兼容性。
- 尚未验证重启后的文件夹再授权。
- 尚未验证多观众或长时间运行的帧率、内存和 GPU 稳定性。
- WebGL context loss 有降级契约，但动态循环完成后需要重新做真实故障恢复。

这些项目应在 TKT-V2-007 的 Hiyori 基线通过后再分批验证，不要与第一轮动态修复同时无限扩张。

### P1 · Live2D 发布许可仍未闭环

允许用户导入不定数量模型可能属于 Live2D 的“可扩展应用”。在获得 Live2D 对当前分发方式的书面许可结论前，只能做本机开发和 Founder 验证，不能把本地导入能力当成可公开分发的已完成产品。

### P1 · 真实设备上的录音、字幕和移动浏览器证据仍不足

DOM 和契约测试不能证明以下体验：

- Mac 实机麦克风与字幕；
- iOS Safari、Android Chrome/Edge 的权限、录制、返回和 bfcache；
- Cloudflare 转写在正式域名的真实可用性与延迟；
- 目标创作者语料上的 CER、首个 partial 延迟和最终修正等待。

建议在代码提交前至少完成一轮 Windows 本机 + 一台真实手机的最短回归；Mac 与正式语料基线单独排期。

### P1 · 尚未形成可发布版本的完整证据包

当前没有针对这一整批未提交变化的统一版本号、变更清单、全量通过记录、网页包复核和 Founder 发布授权。等 P0 处理完成后再做，不要现在先发布一个半成品快照。

建议继续诚实标注；只有在真实用户证明规则反馈价值不足时，再立项语义判断或模型评估。

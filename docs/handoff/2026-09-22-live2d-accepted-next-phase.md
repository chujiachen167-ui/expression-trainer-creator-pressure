## 已关闭

- V2 默认二维观众 bloub：2026-09-21 通过（TKT-V2-006）
- 本机 Live2D：2026-09-22 通过（TKT-V2-007 及验收期内的列表 / 标签修正）

本机 Live2D 现在是可选观众形象，不是默认网页能力。Cubism Core、官方 Framework 构建产物和样例模型仍不进 Git、不进网站包。公开发布前的 Live2D「可扩展应用」许可仍未闭环。

## 下一阶段不是自动开工的事项

这些都还需要 Founder 另下一句话，不能从本验收里推断：

1. **提交 / 推送 / 部署**  
   工作区仍脏。产品代码、测试、文档、研究分支、学校材料、`.codex_tmp` 和 `local-runtime` 必须分开处理。未授权则不 commit。
2. **LiveTalking 真人数字人**  
   仍是平行轨道，不是 Live2D 的升级。缺公开 HTTPS GPU、WebRTC/STUN/TURN、成本、隐私和商业模型许可。
3. **把 Live2D 写成网站已上线**  
   网页版继续只提供 bloub，并说明本机导入入口。

## 建议的下一阶段选项

按当前缺口盘点，Live 轨道关闭后最有价值的开发/产品下一步是：

| 选项 | 做什么 | 不做什么 |
|---|---|---|
| A. 测试基线 | 处理 `npm test` 被研究文档阻断的问题，让主线全量测试可跑完 | 不合并整条 `research/v2-market-position` |
| B. 提交范围拆分 | 把已验收的 V2 / bloub / Live2D 产品代码与文档整理成可审阅的提交切片 | 不把 Core、样例模型、学校材料和研究笔记打进同一笔 |
| C. 学校 / 封闭试点 | 按市场研究把 10–20 人试用当成产品验证，而不是继续加形象轨道 | 不先做商城、账号系统或真人数字人 |
| D. V3 实战房间 | 只在 V3 有兼容观众舞台后再接 bloub / Live2D | 不把 V2 判断改成平台预测 |
| E. LiveTalking 立项 | 仅当 Founder 明确要「面对面真人数字人」时，先做成本与许可页 | 不在训练中途突然插入 |

Founder 于 2026-09-22 指定 **B：先把网站同步**。正式找人试用之前，另做一次上线前优化（兴趣曲线、模糊词判定、优化词提供等），不塞进本次网站同步。

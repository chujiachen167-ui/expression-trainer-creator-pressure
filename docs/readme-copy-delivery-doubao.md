## 这是给谁的

刚做口播、直播、知识分享的人。一开摄像头就忘词、不敢看镜头，讲完自己都不知道哪儿不对劲。

## 你能练什么

- **对着镜头讲一段，长短都行。** 自己出题，或用账号介绍、知识口播、观点、经历这类现成题。
- **口头禅、重复一眼能看到。** 讲的时候有字幕，「嗯、那个、其实」会被标出来，不用事后凭感觉。
- **提前适应被盯着讲。** 能加数字观众，模拟被看着讲的压力；同一题再讲一遍，能对比两次差别。
- **练真会碰到的场面。** 广告植入、热点表态、直播回应、知识口播，都能拿来当题练。
- **想录下来回看也行。** 视频只存在你自己电脑上，不自动上传。

浏览器打开就能试。要完整的离线识别和本机分析，用 Windows 桌面版。

## 怎么试

1. 打开 [read-yourself.com](https://read-yourself.com)
2. 从「镜头基线」开始，允许摄像头和麦克风
3. 选一个题，讲完看字幕，看哪些词被标了出来

## 4. 关键改写决策

- **去掉“先否定再定义”的开场**：原文「不是课程库……就是一块可以反复练的场地」放在段首像产品经理；改为把边界一句话口语化后移到「适合谁」末尾，符合工单第 3、5 节的允许条件。
- **不写死时长**：原文「对着镜头讲 60 秒」→「对着镜头讲一段，长短都行」，对应工单第 4 节“60 秒不是每道题都固定”。
- **砍掉三项排比**：原文「哪里空、哪里重复、哪里在拖」→「哪儿卡壳、哪儿重复」，保留两项、全用口语。
- **补齐隐私缺口**：工单第 6 节要求“录是可选、在本机”出现在第一屏，但原文第一屏只写了「默认不上传」；新增「你能练什么」第 5 条补上，未新增任何工单第 2 节之外的能力。
- **数字观众措辞保守**：原文「按你讲得清不清楚做出反应」涉及反应机制，工单第 2 节注明兴趣曲线是原型估算、不得写成精确科学，故弱化为「模拟被看着讲的压力」，不声称反应精度。
- **避开「诊断」类术语**：「离线转写和本机诊断」→「离线识别和本机分析」，「统计」→「看哪些词被标了出来」，让不做开发的人能懂。
- **alt 中性化**：原文 alt「训练画面」可能暗示截图内容，封面当前可能是起始页，改为「Read Yourself 界面」。

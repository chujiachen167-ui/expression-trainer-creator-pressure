# 四页人工验收调控覆盖审查

日期：2026-08-31。顺序：先完成 Magic UI Vertical Marquee，再进行本次追加审查。

## 范围与证据边界

这是使用 audit 方法进行的**可编辑性代码审查**，不是整站视觉评分。检查起始页、V1、V2、V3 的自有 DOM，以及 V1 训练规则/模型预设弹窗、V2/V3 延迟生成的观众选择弹窗。没有擅改创始人文案、训练算法、真实诊断数据、摄像头权限或后端配置。

浏览器工具明确拒绝自动访问本地文件页，本次未绕过该限制。用 jsdom 执行真实前端脚本进行非渲染 DOM 测试；不加载网络资源。原生 dialog 的 showModal 仅作测试替身，以创建真实应用弹窗 DOM；不据此声称焦点锁定、顶层遮挡或视觉效果已验收。

因此不提供未经实测的 60fps、WCAG 全通过、手机布局全通过或“高级感”分数。

| 等级 | 问题 | 影响 | 修复与入口 |
| --- | --- | --- | --- |
| P1 | 位置/尺寸仅覆盖 9 个大区块 | 无法调整标题、单个按钮、状态点、场景卡等 | UI 参数 → 本页全元素精调：点选、搜索、单元素与伪元素覆盖 |

| P2 | div/label 直接文字、带图标按钮、placeholder 等漏选 | 用户明明看见文字却无法修改 | 文案 → 遗漏文案与占位提示；仅替换文字节点，保留子图标/控件 |

保留的良好机制：浏览器草稿自动保存、项目配置文件导出、组件页可往返切换、训练数据与外观分离。审查未将“所有属性堆在一个长表单”当作解决方案；精调参数按组折叠，组件仍使用独立页。

## 如何使用

1. UI 参数 → 本页全元素精调 → 点选页面元素，然后点要调的文字、按钮或窗口。Esc 退出点选。
2. 颜色与文字、位置与尺寸、间距与边框分组管理；字段留空或点击 ↺ 恢复继承值。
3. 文案 → 遗漏文案与占位提示，用同一个元素选择器修改该元素的文字节点/属性；可修改 V3 场景训练题。
4. 动态弹窗需先打开，或待元素创建后点“刷新元素列表”。不自动打开摄像头/麦克风或改变训练状态。
5. 更改实时保存在当前浏览器；文案页“保存到项目”包含所有新增设置。Marquee 页也提供同一保存动作。

## 明确不作为可伪造文案的内容

- 实时转写、计时器、诊断指标、受众反应和运行状态：可编辑呈现，不能改写结果。当前受众模板摘要、服务连接标签仍跟随业务配置，不被静态文案覆盖。
- 摄像头影像、外部数字人服务内部画面、浏览器权限弹窗、操作系统窗口、独立 Electron 原生设置窗口：不属于这四页的自有 DOM。
- 输入值、密钥、内部配置字段：仍由对应业务表单管理，不通过外观编辑器复制或导出。
- 调控板自身不纳入点选列表，以保留恢复入口。SVG 曲线数据与媒体源不作为外观文案编辑。

个性化以可撤销的 CSS 覆盖保存，不是任意源码编辑器，也没有穷举所有 CSS 属性。动态列表精调按结构位置应用；统一修改组件时应使用专用组件页。

## 自动播放回归修复

旧实现会在减少动态效果时把容器改成 `overflow: auto`，禁用动画并隐藏暂停按钮；此外无条件 `:focus-within` 暂停使点击文字后动画不再继续。本轮移除这些隐式覆盖，增加明确播放模式。后续验收决定采用鼠标悬停暂停，因此删除页面播放按钮与 QA 的手动暂停开关，改为默认悬停暂停。

回归测试覆盖三种播放模式 × 两种系统偏好的初始状态、实际 CSS 规则匹配、悬停暂停配置、配置重载、运行中系统偏好变更与色彩方案。CSS 媒体条件由测试显式展开；不是浏览器逐帧渲染，不证明帧率或无缝衔接观感。

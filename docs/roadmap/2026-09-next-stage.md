# 下一阶段路线：从原型到创作者练习产品

## 产品命题

Creator Pressure 不是平台运营课程、MCN 孵化后台或通用视频编辑器。它面向准备开始或刚开始做自媒体的人，把“知道应该怎么说”变成“面对真实镜头反复练到能够说出来”。

核心闭环是：选择表达任务 → 完成一次练习片段 → 获得同步诊断 → 回看自己的镜头状态 → 同题重练 → 对比前后变化。

## 执行顺序

1. 冻结当前创作者压力训练原型，保留上游诊断底座、署名和第三方清单。
2. 完成摄像头与麦克风选择、录制状态、回看和本地导出，使 V1 形成可独立使用的练习闭环。
3. 建立目标用户录音基线，分别衡量实时字幕与最终文本精度，再决定是否引入双阶段 STT。
4. 抽离全产品文案，首先交付简体中文与英文界面；诊断语言独立配置，不把中文诊断规则机械翻译成英文。
5. 在数字观众智能化前停止开发，先完成成本、隐私、供应商和赞助评估。

## 数字人停止门

以下任一事项出现时，不直接接入或付费：

- 需要云端数字人、商业模型、付费 API、授权形象或持续 GPU 服务。
- 用户的音视频需要离开本地设备。
- 供应商条款限制演示、开源发布或后续商业化。
- 没有可替换 Provider，导致产品被单一供应商锁定。

进入下一步前需要形成一页成本表：免费本地方案、赞助方案、自费方案分别列出一次性成本、持续成本、数据去向、许可边界和退出方式。

## 暂不纳入

- 平台流量运营、账号矩阵、投放与商业代运营。
- 以课程数量为核心的知识付费商城。
- 自动发布到抖音、小红书、视频号等平台。
- 在用户没有明确同意时上传录音、录像或逐字稿。

## 本轮边界

- B 模式是静音的数字观众：只用表情、姿态与文字反馈表达兴趣，不播报、不追问、不打断。
- C 的真人数字人对话不属于本轮，也不再被描述成 B 的高级版。
- Live2D 只支持已安装本机版的用户从本地导入；没有账号、上传、后端或创意工坊。
- V2 继承 V1 的转写后完整诊断、粘贴稿件、生成优化稿能力。
- 兴趣曲线只记录可解释的表达证据，不用随机波动伪装“实时感”。

## 开源研究结论

实现前已完成候选项目与许可证核对，详见 `docs/research/2026-09-10-v2-remediation-open-source-review.md`。

没有发现可以直接嵌入、同时满足“实时中文转写 + 用户选择的假想观众 + 可解释兴趣曲线”的成熟开源组件。本轮采用可复用的公开思路：

- 借鉴 Converser 的分时间窗口指标结构；
- 借鉴 PSST 的演讲风格维度拆分；
- 保留本项目面向不同假想观众的确定性规则；
- 不引入 iamspeaker 的 TTS/对话栈；
- 不引入 DAiSEE 的真实观众摄像头识别与隐私负担；
- Live2D 继续使用官方 Cubism Web SDK 本机桥接，不并入第二套渲染器。

## 已完成

2. 兴趣曲线改为基线加证据事件；没有证据时不反复写入同一分数。
3. 增加具体性、例子、证据、边界/代价、相关性、信息密度等正向事件，使曲线能根据表达证据回升。
4. 曲线改成阶梯线，避免视觉插值制造并不存在的渐变判断。

8. 增加开发专用的官方 Hiyori 样例入口；仅在未打包的本机 Electron 中、带显式启动参数时启用。

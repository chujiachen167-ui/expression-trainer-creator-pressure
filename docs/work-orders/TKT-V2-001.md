## 交付范围

### 1. 会话与时间数据

- 建立可独立测试的会话 / 逐字稿片段 / 判断事件模型；DOM 只负责展示。
- 每轮冻结选题、受众、压力、识别语言、判断器版本。设置变动明确从下一轮生效，避免无提示修改当前比较条件。
- 片段至少包含会话 ID、片段 ID、修订号、正文、临时或确认状态、来源、可用的起止时间和时间精度标记。判断事件包含片段引用、时间或时间范围、受众、类型、证据、解释、建议和判断可靠程度。
- 优先在转写适配入口产生数据，保留旧事件兼容。临时字幕修订不得反复扣分；同一确认结果重复到达应幂等；相同文字在不同片段真实重讲不能错误去重。
- 使用同一会话时钟。区分采集时间、音频片段边界与结果到达时间。有真实词级时间才显示词级定位；没有就显示片段范围或“约”。禁止把网络返回时间当成发言时间。
- 浏览器 Web Speech 只能得到粗略时间时，明确估算；手工粘贴全文没有真实时间，不生成“前三秒”结论或伪造录像跳转。
- 结束训练应等待本轮已接受的最终字幕完成，再形成复盘；旧轮迟到回调不得污染新轮。空白、失败和队列未收尾均有真实状态。

### 2. 判断机制与边界

- 独立定义可替换的判断器接口。本单先实现无需新增付费服务的规则版本，并如实标识；预留未来模型实现，不伪造已经完成语义理解。
- 统一事件用于曲线、右侧解释和未来头像状态。若保留 V2 旧追问，须引用相同事件并有去重、冷却；V1/V3 原路径保持兼容。
- 最少支持三种受众偏好：快速浏览者、零基础观众、怀疑型观众。差别必须反映在依据和建议上，不能只是随机改分数。
- 只对有依据的局部信号作判断；“因为”“比如”或数字不能自动证明内容质量、证据真实性。孤立出现“其实”“我觉得”“it”“if”不能直接判为不专业。
- 区分正常语法重复与重复铺垫；允许叙事、悬念、不同观点。不用停顿或口吃推断人格、能力或受欢迎程度。
- 无可靠依据时显示“信息不足 / 暂无明确变化”。低把握的关键词提示应为可复核建议，不用强烈掉分制造压力。连续相同信号不要叠加惩罚。
- 开场分析绑定全轮真正的开头；定义练习开始和首个有效发声的区别。时间精度不足时退回“开场片段”，不虚构精确三秒判断。转写失败不计入用户表现。
- 分数若保留，标为相对模拟指标，禁止百分号式留存概率或随机漂移。量表、初始值、上限、平滑规则和版本写入说明；固定输入、配置与版本应得出可复现结果。
- 新增反馈提供中文与英文；英文规则应能处理基本词边界和大小写，不直接复用中文子串统计。不能判断的情况明确提示，不能无依据出高分。

### 3. V2 右侧栏

- 标题“模拟观众兴趣趋势”，附简短边界说明。
- 曲线横轴使用实际会话秒数或明确的片段时间范围；保留整轮数据，图表可抽样但不得丢失复盘依据。尚无数据时不画假曲线；中断或等待结果时显示缺口 / 待处理状态，不把等待绘成兴趣下降。
- 训练中只突出当前状态、最近一个主要事件及一条可执行提示；避免事件洪流和强制打断。
- 点击或键盘选中事件可定位对应逐字稿，高亮证据，显示原因和建议；移动端可点按访问同等信息。
- 有可回放录像且时间映射成立时提供跳转；考虑录制晚于练习开启的偏移。未录制、素材已丢弃、播放器暂不能 seek 或时间未知时回退到逐字稿，不提供虚假可用按钮。
- 尊重现有配色与组件样式，新样式限定 V2。窄屏先保留核心练习，曲线和复盘顺序展开，不能撑破页面。

### 4. 本轮复盘与同题重练

- 停止后展示最多三个关键事件、开场判断（或信息不足）、一条下一轮训练动作。
- 同题重练保留题目、受众、压力与判断版本；保留上一轮基线，至少支持本页两轮比较。
- 比较呈现实际可比变化、引用前后原句；条件或版本不同则说明不可直接比较。不能默认第二轮必然变好，不能靠内部得分证明用户能力提高。
- 会话正文默认留在本页内存；提供显式“保存复盘 JSON”以便用户保留两轮文本、依据与时间精度。导出前能看出含逐字稿；不附音视频、密钥或设备信息。刷新前提示尚未保存状态，不阻断正常离开。
- 不把训练记录混入公开的项目参数 JS/JSON；新评估参数、面板外观参数与用户记录分开。

### 5. 调控板与打包

- 新增 V2 曲线 / 复盘外观参数放入明确的对应区域，至少含颜色、字号、图表高度与提示密度，接入既有项目配置保存 / 重置路径。
- 调参不能修改已经产生的真实训练结果；算法参数若可调，记入下一轮配置快照及比较条件。
- 新增浏览器运行文件必须纳入 `scripts/package-web.js` 白名单。开发用样例与回放工具不得自动出现在正式用户页面。

## 行为检查与 Founder 验收

提供开发专用、可重复输入的片段回放入口，复用正式数据接口，明确标注测试数据；Mac 验收未完成时可以用它推进本单。不得把演示数据写入用户真实会话。

必须覆盖的行为：

1. 无输入与输入失败不生成评分；粘贴文本不产生精确时间结论。
2. 同一片段重复回调、临时修订、UI 重绘不重复生成事件；不同片段的真实重复能被保留。
3. 不等间隔输入落在对应秒数；网络延迟不平移已知的音频时间；旧轮迟到结果不串轮。
4. 停止时最后一段纳入正确轮次；新轮与旧轮的状态隔离。
5. 中文 / 英文正常语气词不被一律扣分；叙事开头不被强制按“没结论”判差；不同受众有可说明的差异。
6. 曲线事件定位原句；可用录像跳转与无录像回退分别成立。
7. 同题重练得到真实前后比较；条件改变时不装作可直接比较。
8. 全局配置保存包含新增外观参数，但不夹带训练正文；公开打包有新运行文件、没有开发回放入口。

新增测试应检查状态和输出，不以“源码里有某个字符串”代替行为。相关测试通过后执行一次 `npm run check`、`npm test`、`npm run package:web`、`git diff --check`。先检查打包输出目录没有用户独有文件；打包脚本会重建 dist。若旧测试固定了已明确更改的行为，更新断言并说明，不能删测掩盖失败。

执行者不做替 Founder 判定“高级感 / 好用”的自动视觉验收，不反复截图刷测试。保留必要逻辑与打包检查；Founder 自行看效果。

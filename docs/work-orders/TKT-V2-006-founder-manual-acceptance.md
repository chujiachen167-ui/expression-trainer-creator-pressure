## 四、Founder 人工验收

- [x] **1. 默认 bloub 舞台效果**
  - 操作：打开 V2，应用默认二维观众模板，保持默认窗口尺寸观察 10 秒。
  - 预期：白色大饼脸已被替换；bloub 尺寸足够大且位于观众区域中央；深色舞台上眼睛清晰；默认没有突兀的浅色卡片；不遮挡兴趣曲线、字幕或主要操作区。
  - 失败证据：截取包含完整窗口、窗口尺寸和遮挡位置的截图。

- [x] **2. “V2 二维观众”控制项**
  - 操作：依次调整大小、横纵位置、墨色、纸色、卡片、标签和表情停留时长，然后恢复到希望保留的值。
  - 预期：舞台立即响应；控件名称与结果相符；没有刷新、跳页或配置丢失；控制面板与舞台显示一致。
  - 失败证据：记录出错控件、输入值、实际结果，并附 10 秒左右录屏。

- [x] **3. 表情预览完整性**
  - 操作：预览四种训练状态，再任选一个扩展表情，并检查“思考”和“眨眼”。
  - 预期：每次选择都能立即看到对应表情；标签与所选项目一致；预览状态保持到下一次预览或正式判断；预览本身不会伪造兴趣分数或反馈事件。
  - 失败证据：录制选择项、标签和实际表情同时可见的画面，并写明不一致的名称。

- [x] **4. 正式训练中的反馈节奏**
  - 操作：进行 30—60 秒自然表达，先说一句明显含糊的话，再把同一意思改成具体、可验证的说法；观察事件、证据摘录和观众表情。
  - 预期：反馈能指向刚才说过的具体片段；观众表情约停留 1.6 秒后回到常态，不再拖沓约 5 秒；没有无缘无故跳表情、改分或重复触发。
  - 失败证据：保留带声音的录屏，附实际转写文本、事件卡片和大致触发时间。

- [x] **5. “具体观众”差异是否成立**
  - 操作：用同一段 30 秒内容，分别选择两类差异明显的观众或平台模板进行排练；第二次不要改内容。
  - 预期：差异能解释为不同观众关注点或规则权重，而不是随机换皮；反馈仍然引用实际说过的话；界面不会声称获得了平台后台、真实留存率或推荐概率。
  - 失败证据：分别截图两次所选模板、反馈结论和证据摘录，并标明哪一处像“平台预测”或哪一处没有差异。

- [x] **6. 无证据时的诚实性**
  - 操作：提交空白内容，或提交不包含可判断信号的短句；若使用粘贴文本，确认系统不知道真实说话时长。
  - 预期：系统显示空状态、证据不足或低置信度，不凭空扣分；不会声称“前三秒”“留存下降”或其他无法由当前输入证明的结论。
  - 失败证据：保留输入内容、结果和相关文案的同屏截图。

- [x] **7. 整体排练价值**
  - 操作：完成一次约 1 分钟的正常练习，并根据一次反馈重说同一段内容。
  - 预期：Founder 能明确说出“我在面对哪类观众练习”以及“第二次具体改了哪句话”；体验像排练和反馈，而不是一个假装知道平台结果的评分器。
  - 失败证据：写下最影响使用的一处问题，并附对应截图或录屏；不要只写“感觉不好”。

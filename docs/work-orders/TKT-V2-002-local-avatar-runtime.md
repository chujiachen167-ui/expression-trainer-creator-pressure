# TKT-V2-002 · 本地观众运行时 MVP

状态：**CONDITIONAL**。本地导入、校验、登记和四态适配已落地；Founder 授权后已用官方 Core、官方 Cubism Web Framework 与官方 Hiyori 样例取得真实 WebGL 像素，并验证 Pose、Shader、贴图方向及 context loss 降级。尚未完成用户自有四表情模型的 Electron 端到端验收、重启再授权和多观众性能验收；公开发布还需完成“可扩展应用”许可审核。

## 下一执行门

- 用用户自有且明确授权的模型，在 Electron 文件夹选择器中完成 `listen / confused / interest / drop` 四态视觉验收。
- 补测重新启动后的文件夹再授权，以及同一模型挂到多观众窗时的内存、GPU 和帧率。
- 对依赖 idle motion 才能得到正确初始姿态的模型给出兼容性提示；当前只把 Pose 纳入必需的静态呈现链。
- 发布前取得 Live2D 对“可扩展应用”的书面许可结论；在此之前状态保持 CONDITIONAL。

## 目标

让在本机安装并运行 Read Yourself 开源项目的用户，可以导入自己持有的本地 Live2D 模型并将其用作观众形象；同时保持 LiveTalking 为训练开始前主动选择的面对面真人数字人路径。

## B 轨：本地 Live2D 导入

- 仅从用户本机读取模型，不上传到 Read Yourself 服务器。
- 第一版只接受模型文件夹，不接受 zip、远程 URL 或可执行脚本。
- 校验单一 `.model3.json`、引用路径、资源边界与文件规模。
- 导入的形象只改变视觉呈现，不改变 Audience Persona、判断规则或分数。
- 复用 `listen / confused / interest / drop` 四态；模型缺少对应表情时安全降级。
- 本机像素渲染只在 WebGL、用户自行放置的 Cubism Core、官方 Framework bridge 与 Shader 都可用且读到非透明像素时绘制导入模型；否则明确恢复官方 SVG 四态，不出现空白观众窗。
- 本地选择可保存；生产网站不得显示为云端资产或上传成功。

## C 轨：面对面 LiveTalking

- C 不是压力事件，也不会在用户表达途中突然进入。
- 用户在训练开始前主动选择该模式和可用数字人，数字人全程在场。
- C 与 B 平行，不是 B 的高级版或进化形态。
- 本阶段不伪造男性、女性、肤色或其他尚未实际提供的数字人素材目录。
- 没有真实 GPU、HTTPS、WebRTC 成功证据时，不得宣称线上已经接通。

## 明确不做

- 后端、数据库、账号或云端文件存储。
- 创意工坊、社区、分享、发布、审核、交易或分成。
- 用户模型上传到 `read-yourself.com`。
- 任意用户脚本执行、远程模型加载或用户自定义诊断逻辑。
- commit、push 或 Cloudflare 部署。

## 验收

1. 本地导入入口可被键盘操作，并明确显示“只在本机使用”。
2. 合法模型目录通过验证并进入本地可选列表。
3. 缺文件、路径越界、远程引用、超限资源与不支持格式均给出具体错误。
4. 尚未接入渲染器、真实模型加载失败或 WebGL 不可用时明确恢复 SVG，不出现空白观众窗。
5. 四态事件仍由现有 V2 判断事件驱动，导入模型不改变判断结果。
6. 生产网页打包不包含用户本地模型、Cubism Core 或本地绝对路径。
7. 相关语法、契约与打包测试退出码为 0。

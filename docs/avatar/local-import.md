# 本地 Live2D 导入（MVP）

本功能只服务于把 Read Yourself GitHub 开源项目安装并运行在本机的用户。

- 入口只在 Electron 或本地开发环境出现；正式网站不会显示“上传模型”入口。
- 选择的是本地文件夹，不接受 zip。
- 文件夹必须包含且只能包含一个 `.model3.json`，清单引用必须指向文件夹内的相对文件。
- 脚本、HTML、远程 URL、路径穿越和明显超限文件会被拒绝。
- 项目只在本地配置中登记模型信息，不把模型复制或上传到 Read Yourself，也不提供账号、云存储、分享或社区入口。
- Electron 页面只保存不透明模型 ID，不保存本机绝对路径。文件读取权限仅在用户本次明确选择文件夹后的应用会话中有效；重新启动后如需绘制，请重新导入该文件夹。
- 当前仓库不携带 Cubism Core 或第三方模型。本地运行时可以在用户自行放置 Core 且 WebGL 可用时绘制导入模型，并播放模型自带的 Idle / 反应动作；否则明确恢复默认 bloub 观众，不能把“登记成功”称为“Cubism 已随网站上线”。

导入的数字形象只改变 Avatar 的呈现，不改变 Audience Persona、诊断规则或受众判断逻辑。
